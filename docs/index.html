Dracula_OS-Theme

Experiência Dracula unificada para Pop!_OS / GNOME: 2235 ícones, cursor, GTK, shell, sons, app themes e launcher em pt-BR. Build reprodutível — instalação reversível — auto-resiliente a apt upgrade.

Instalar GitHub

Cobertura

O tema cobre da camada visual mais profunda (cursor, ícones simbólicos) até a integração com extensões e apps específicos — todo monorepo, um único install.sh.

●Tema de ícones

Dracula-Icones com 2235 arquivos (apps, mimetypes, places, devices, status, emblems, emotes). 1.558 symbolic icons propagados dos heritages com merge único — lookup local sem cair em Adwaita/hicolor.

●Cursor + GTK 2/3/4

Dracula-Cursor em escala 32px e tema Dracula-standard-buttons com override do shell para integração com Pop!_OS Launcher.

●Pop!_Shell + Pop!_Cosmic

Substituição do dark.css nas duas extensões (com backup). Detecção de regressão por comparação byte-a-byte contra source canônico.

●Launcher em pt-BR

Cópia user-local da extensão pop-cosmic@system76.com com strings traduzidas: Library Home → Início, Create Folder → Criar pasta, diálogos completos. Sobrevive a apt upgrade.

●App themes integrados

Kitty, qBittorrent, GNOME Terminal (dconf), Spicetify/Spotify, Obsidian (itera vaults), Telegram, Discord (BetterDiscord/Vesktop/Vencord), OnlyOffice. Spicetify usa o setup do Spellbook-OS; recuperação pós flatpak update via scripts/atualizar_spicetify.sh --auto-fix.

●Higiene do app-grid

Esconde gnome-session-properties (rótulo confuso) via NoDisplay=true e remove pastas vendor (Utilities, YaST) do rodapé do launcher.

●Ícones de jogos Steam

Patcher universal: varre .desktop Steam, gera PNG 256×256 da capsule (library_600x900.jpg) com square crop. Reaplicado por APT hook.

●Auto-resiliência pós-upgrade

APT hook dispara reaplicar_tema.sh automaticamente após cada apt upgrade. 15 seções idempotentes em ~3.4s.

●Tema de som Pop

Restaura org.gnome.desktop.sound theme-name='Pop' quando o GNOME upgrade reseta. Sons restaurados em ~/.local/share/sounds/Pop/.

Instalação

Pop!_OS 22.04 / GNOME 42.x / X11 ou Wayland. Sem dependências obscuras — só bash, git, convert, rsvg-convert.

Rota curta (ambiente novo)

Clone, build e install completo em uma linha:

git clone https://github.com/AndreBFarias/Dracula_OS-Theme.git
cd Dracula_OS-Theme
./build.sh && ./install.sh --bootstrap

Rota controlada (passo-a-passo)

Útil para revisar o que vai acontecer antes:

# Build (gera dist/)
./build.sh

# Instala apenas o tema do usuário (sem mexer em /usr/share)
./install.sh --user

# Adiciona Pop!_Shell CSS, launcher pt-BR, higiene, ícones Steam
./install.sh --pop-shell-css

# APT hook para auto-reaplicação após apt upgrade
sudo ./scripts/instalar_apt_hook.sh install

Reaplicar (após upgrade)

Idempotente. Roda em ~3.4s e cobre 15 seções:

./scripts/reaplicar_tema.sh

Já dispara automaticamente via APT hook se você instalou com --apt-hook.

Desinstalar

Reverte tudo (com backup automático em ~/.cache/dracula_os_backup/):

./uninstall.sh
